ADARSH SINGH - PERSONAL PORTFOLIO

This is a simple white-theme portfolio made with HTML5 and CSS3 only.

Files:
- index.html
- style.css
- assets/adarsh-professional.jpg

To open:
1. Extract the ZIP file.
2. Keep index.html, style.css and the assets folder together.
3. Open index.html in your browser.

Before submitting:
- Replace adarsh@example.com with your actual email in index.html.
- Replace the generic GitHub and LinkedIn links with your own profile links.
- Add your college name if you want to show it.
- The project entries are concepts, not completed products.

The contact form uses mailto and browser required-field validation. It does not store submissions on a server.
